Make your own.

This site is a phone home screen of small apps. Each one started as a few sentences typed to Claude, which wrote the app, tested it, and published it. You can have your own in about half an hour, without writing any code.

You describe an app→Claude builds and tests it→It's live on your phone

What you need

  • 🐙
    A GitHub accountFree, at github.com. It stores your site and publishes it with GitHub Pages, also free.
  • ✳️
    Claude with Claude Code on the webAt claude.ai/code. Claude works in a "cloud session": a private computer in the cloud with your site's files, so nothing runs on your phone or laptop.
  • 📱
    Your phoneWhere the site lives as an icon on your home screen.

Set it up

  1. Create your site's repository on GitHub

    On github.com, tap New repository. Name it exactly yourname.github.io, using your GitHub username. Make it Public, tick Add a README, and create it. That name tells GitHub to publish it as your website at https://yourname.github.io.

  2. Connect Claude to GitHub

    Open claude.ai/code and connect your GitHub account when it asks. Allow Claude's GitHub app to access your new repository, so Claude can read and publish its files.

  3. Start a cloud session and hand Claude the skill

    Start a new session with your yourname.github.io repository selected. Download the skill file below, attach it to your first message, and send:

    Set up my app launcher site using this skill. Make it mine: call it "[your name]'s Apps", and pick colours you think suit it. Push it live and tell me when to check my phone.

    Claude creates the launcher page, the shared styles, the app list and a CLAUDE.md file of house rules, so every later session follows the same conventions.

  4. Put it on your home screen

    When Claude says it's live, open https://yourname.github.io on your phone. On iPhone, tap Share, then Add to Home Screen. On Android, open Chrome's menu and tap Add to Home screen. It now opens full screen like an app, and it keeps your apps' data safer than a browser tab.

  5. Ask for your first app

    Describe what you want, as plainly as you'd tell a friend. Claude builds it in its own folder, tests it on a phone-sized screen in light and dark mode, adds a tile, and publishes it. Reopen your home-screen icon a minute later and it's there.

The skill file

A skill is a set of instructions Claude reads before it starts. This one teaches Claude how sites like this are laid out, the house rules (phone first, light and dark mode, your data stays on your phone with an export, publish straight away), and how to test each app before publishing.

Download SKILL.md

Attach SKILL.md to your first message in a session. If your Claude app lets you add your own skills in its settings, upload the .zip there so every chat has it. You can also ask Claude to save it in your repository under .claude/skills/, so cloud sessions on that repository always load it.

Things to ask for

  • An app that rolls a die to pick my next activity, favouring things I've been neglecting.
  • A list of songs I want to learn, with a slider for how far along I am and a button to count performances.
  • A guitar tuner and metronome that work on my phone.
  • A page of my long-term goals, broken into steps, where I can add dated notes.
  • Turn this document into an app I can browse. (Attach the file.)

Tips

  • Say what matters, skip the how. "I need to drink water about 8 times a day" is more useful than naming a setting.
  • Changes are live in a minute or two. If you don't see one, close and reopen the home-screen app.
  • Just asking a question? Say "just answer, don't change anything", and Claude won't touch the site.
  • Your data stays on your phone. Apps save to the browser, not to a server. Use each app's Export now and then: it saves spreadsheets, a readable summary and a backup.
  • Apps that need the internet. If an app needs outside data, such as maps, Wikipedia or song files, Claude may ask you to allow those sites in your cloud environment's network settings, so it can test them. Your phone isn't limited this way.
  • Start over any time. Each new session reads the house rules in CLAUDE.md, so it picks up where the last one left off.
