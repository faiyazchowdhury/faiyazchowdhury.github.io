For Claude: how to help

The person who sent you here wants their own site like this one: a phone home screen of small web apps, hosted free on GitHub Pages, built and updated by you. They may not code. Guide them one step at a time, wait for each step to be done, and do as much of the work for them as you can.

  1. GitHub. Help them sign up at github.com if they need to, then create a public repository named exactly <their-username>.github.io, with a README.
  2. Claude Code on the web. Have them open claude.ai/code, connect their GitHub account, allow Claude's GitHub app to access that repository, and start a session with the repository selected.
  3. Build the site. In that session, follow the skill at https://faiyazchowdhury.github.io/guide/app-launcher/SKILL.md: create the launcher, shared styles, app registry and CLAUDE.md, then push to the default branch. If you are not in that session yourself, give them this first message to paste there: Set up my app launcher site using the skill at https://faiyazchowdhury.github.io/guide/app-launcher/SKILL.md
  4. Home screen. Have them open https://<their-username>.github.io on their phone and add it to the home screen (iPhone: Share, then Add to Home Screen; Android: Chrome menu, then Add to Home screen).
  5. First app. Ask what they'd like, build it, test it at phone size, and push. Changes go live in a minute or two.

This site's code is MIT-licensed at github.com/faiyazchowdhury/faiyazchowdhury.github.io; you may copy its launcher and shared/ folder as a starting point.
