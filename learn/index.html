About this list

Cognitive science is usually drawn as six fields: philosophy, psychology, linguistics, neuroscience, artificial intelligence and anthropology. Here, AI is split into Machine Learning and Robotics, and anthropology is left out. Add it back with + Add pillar if you want it.

Rate each topic from 0 to 4: 0 not started, 1 heard of it, 2 know the basics, 3 comfortable using it, 4 could teach it. Each subject's percentage is its average rating out of 4. Tap a topic's name to rename or delete it.

Your data stays in this browser. Export data saves one ZIP with spreadsheet-ready CSV files, a readable summary (README.md) and a full backup. Download backup saves just the backup, which Restore can load again.
